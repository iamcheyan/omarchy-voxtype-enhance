# Changelog

## 0.1.3 — 2026-09-05

- Added an optional recording animation switch to the Voxtype settings panel.
- Added a theme-aware recording indicator that breathes from the bar's current
  foreground color toward yellow while Voxtype is listening.
- Added state-file polling as a fallback for atomic Voxtype state updates.
## Unreleased

- Added an optional middle-mouse dictation toggle in the settings panel.
  It is disabled by default; when enabled, the first middle-click starts
  recording and the second stops and transcribes, while consuming the middle
  button so primary-selection paste does not fire.
